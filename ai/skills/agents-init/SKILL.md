# Инициализация документации агентов (AI-AGT-8, AI-A19)

Цель: один источник знаний для всех агентов. `AGENTS.md` — канон; `CLAUDE.md` — только импорт и
специфика Claude Code; навыки — `.agents/skills/<имя>/SKILL.md`; `.claude/skills` — симлинк.

## 0. Сначала посмотри, что есть

Выполни `ls -A`, `git remote -v`, прочитай существующие `AGENTS.md`, `CLAUDE.md`, `.claude/`, `.agents/`.

- Если проект **чужой/командный** (есть чужой `CLAUDE.md`/`AGENTS.md`/`.agents`, remote не личный) —
  **ничего не переписывай**: опиши, что агенты прочитают нативно, и остановись.
- Если уже есть `CLAUDE.md` с содержательным текстом, а `AGENTS.md` нет — предложи перенести знание в
  `AGENTS.md`, а в `CLAUDE.md` оставить `@AGENTS.md` и специфику; перенос делай только после согласия.
- Существующие файлы не перезаписывай; покажи план и дождись согласия.

## 1. `AGENTS.md` (корень, ≤ 200 строк)

Без дублирования документов проекта — только то, без чего агент ошибётся:

- что это за проект и для чего (2–4 строки);
- карта документов: где что лежит и как искать по ID (`grep -n`), а не «прочти всё»;
- жёсткие запреты (секреты, необратимые команды, публикация);
- как запускать сборку, тесты, проверки — точные команды;
- протокол работы (план перед многофайловой правкой, размер коммитов, язык);
- строка «текущее состояние», если проект идёт по этапам.

Для подкаталогов со своими правилами — вложенные `AGENTS.md` (короткие). Личное — `AGENTS.local.md`
(добавь в `.gitignore`).

## 2. `CLAUDE.md`

Первая строка — `@AGENTS.md`. Дальше только то, что относится к Claude Code (права, навыки, память).
Содержимое `AGENTS.md` не повторяй. Без строки-импорта файл считается ошибкой (замечание в отчёте
лаунчера).

## 3. Навыки и симлинк

```sh
mkdir -p .agents/skills .claude
ln -s ../.agents/skills .claude/skills   # симлинк, не копия
```

Навык — `.agents/skills/<имя>/SKILL.md` с полями `name:` (равно имени каталога) и `description:`.

## 4. `.gitignore`

Добавь, если нет: `AGENTS.local.md`, `CLAUDE.local.md`, `.claude/settings.local.json`.

## 5. Проверь результат

- первая строка `CLAUDE.md` — `@AGENTS.md`; `wc -l AGENTS.md` ≤ 200;
- `readlink .claude/skills` = `../.agents/skills`;
- у каждого навыка `name:` = имени каталога;
- ничего из секретов в новых файлах нет.
В конце коротко перечисли созданные файлы.
